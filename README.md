# ML Media Master

Plugin WordPress para conversão de JPG, JPEG e PNG em WebP, com lotes AJAX, compatibilidade com uploads antigos e suporte a licença Free/Full.

## Estrutura atual

- Pasta do plugin: `ml-media-master`
- Arquivo principal: `ml-media-master.php`

## Status

Base preservada para manter compatibilidade de atualização com instalações existentes.

## Observação

Nesta fase, o repositório mantém a identidade técnica atual do plugin para evitar instalação paralela ou perda de continuidade nas atualizações.
